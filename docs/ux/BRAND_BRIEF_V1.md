# LifeMate — Brand & Visual Brief v1

## Brand idea
**LifeMate = همراه رشد، نه ناظر.** The visual language combines calm, momentum, independence and connection.

## Audience behavior
The initial teen experience must feel attractive to a 13-year-old without using preschool/childish motifs. The same identity must remain credible at 16, 20 and adulthood. Parent surfaces share the brand but prioritize clarity and actionability.

## Visual direction
- Soft geometric forms, rounded but not toy-like.
- Controlled illustration: meaningful empty states, learning moments and onboarding; avoid decorative overload.
- Primary direction: deep plum/indigo anchor + lavender support + mint success/calm + restrained peach warmth + light neutral cloud surfaces.
- Dark mode must be designed, not mechanically inverted.
- Typography direction: **Vazirmatn** for Persian UI where licensing/package validation passes; Latin companion chosen for metric harmony.
- Iconography: rounded, consistent stroke; no cartoon school clichés as the core brand mark.

## Logo/app icon principles
The mark should express **path + companion + growth** using a simple abstract form readable at favicon/app-icon size. Avoid book/pencil/graduation-cap as the primary symbol because LifeMate is broader than school. The icon must work on Android adaptive icon, PWA manifest icons, apple-touch-icon and favicon.

## Experience tone
Teen: encouraging, calm, graphical, choice-oriented. Parent: concise, trustworthy, actionable. AI: warm but never manipulative, dependency-seeking or presented as a human clinician.

## Motion
Use short purposeful transitions to explain hierarchy/status. No attention-hijacking animation, reward explosions or endless streak pressure. Respect reduced motion.

## Figma artifact
Phase 1 design file: `LifeMate — Product UX & Brand v1`.
Initial editable board includes color direction and concept frames for Teen Today, Parent Overview and Login/Welcome. This is a direction board, not a final UI kit.

## Canva role
Canva is approved for supporting illustration/educational visual asset exploration. Final UI layout, tokens, components and interaction specifications remain controlled in Figma so implementation does not depend on flattened artwork.

## Acceptance
A future screen should be rejected if it feels like a generic school ERP, a surveillance dashboard, or a small-child game. It should feel like a polished personal companion that happens to understand school and family.
