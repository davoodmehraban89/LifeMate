# پژوهش کتاب‌ها و آموزش آپارات: ابتدایی، ۲۰۲۶-۱۰-۰۹

این بستهٔ LifeGuide فقط پژوهش و گردآوری فرادادهٔ عمومی است. **تماشای کامل ویدیو، ارزیابی مستقل صحت تدریس، پخش iframe روی Android/Safari و دسترسی بدون VPN از داخل ایران: UNVERIFIED.** هیچ ویدیویی دانلود، بازنشر یا رونویسی نشده است؛ فقط صفحه، نمایه، API فراداده و فهرست کتاب بررسی شده‌اند. PDF رسمی کتاب برای خواندن فهرست استفاده شد و فایل کتاب در مخزن بازنشر نشده است.

## نتیجهٔ پیمایش فراداده و رد نگاشت

۵۵۴ endpoint فرادادهٔ نمایه‌ها خوانده شد:۴۱۲ پاسخ معتبر،۱۴۱ پاسخ429 و یک410. پس از فاصله،۳۶ نامزد مستقیم جست‌وجو به‌صورت آهسته بررسی شدند و هر۳۶ فراداده معتبر دادند؛۲۳ مورد مکمل با نگاشت دقیق پذیرفته شد. نمونهٔ [endpoint فرادادهٔ صفحه۲ ریاضی۲](https://www.aparat.com/etc/api/video/videohash/vvo9vt9) شامل عنوان/کانال/مدت/وضعیت رایگان است. خروجی API می‌تواند URL فایل ویدیو هم داشته باشد؛ آن URLها دانلود یا در داده نگهداری نشدند.

- `rvpj8z1`، صفحه۱۳۹ ریاضی۲:410؛ حذف شد.
- `g275823`: نمایه صفحه۳۲ اما عنوان API صفحه۲۳. `Eukq6`: نمایه۶۶/۶۷ اما API۶۷/۶۸. هر دو کنار گذاشته شدند.
- ۷۹ مورد429 مربوط به نمایهٔ پنجمِ ناسازگار بود. **۶۲ مورد429 ریاضی۴ فقط در سطح نمایه** پذیرفته شد؛ خطای429 به معنای لینک مرده نیست، اما تأیید پخش هم نیست. UI باید وضعیت سطح تأیید/دسترسی نامعلوم را نشان دهد.
- پلی‌لیست‌های4656696،588438 و1284316 صفحهٔ عمومی داشتند، ولی fetch محتوای همهٔ آیتم‌ها را روشن نکرد؛ کامل‌بودن آن‌ها UNVERIFIED. پلی‌لیست7064138 دربارهٔ روش تدریس آموزگاران است.

## شکاف‌های باقی‌مانده

کاتالوگ رسمی برای هر شش پایه دارد؛ پوشش ویدیویی کامل برای هر کتاب ندارد. ریاضی۱، نگارش، خط تحریری، چاپ‌های آزمایشی/دینی، پژوهش/مهارت‌های فناوری و بیشتر درس‌های فارسی/علوم۵/۶ هنوز نیازمند گردآوری و بازبینی انسانی هستند. واحدهای اصلی فارسی/علوم با توالی رسمی ثبت شدند؛ اجزای فرعی شعر/تمرین/جلسه/پروژه ادعای پوشش کامل ندارند. برای قرآن۴/۵/۶، شمارهٔ درس از فهرست رسمی ثبت شده و عنوان کلی «درسN» جای نقل نام سوره/جلسهٔ نامطمئن را گرفته است.

برای پذیرش واقعی باید نمونه‌های هر مدرس روی دستگاه پخش شوند؛ صحت توضیح، سازگاری با نسخه/صفحه، وضوح تصویر/صدا، نبود پیش‌نمایش پولی و ترتیب کل مجموعه بررسی و جداگانه ثبت شود. این بسته فقط فراداده است و ادعای اجرای importer، آزمون Backend، Build یا پذیرش دستگاه ندارد.
