# 0016 — مسیر APK اولیهٔ برنامهٔ شخصی کودک

وضعیت: ACCEPTED برای D-A، صرفاً APK اولیهٔ شخصی — ۲۰۲۶-۱۰-۱۹. هویت/مجوز نسخهٔ آنلاین و سرویس زنده تغییر نمی‌کند.

مالک بستهٔ برنامهٔ هفتگی، تکرار، یادآوری، تیک مستقل و حفظ داده پس از بازگشایی را برای APK اولیه تأیید کرد. تأیید، مجوز deploy یا بازکردن برنامهٔ خصوصی برای نشست دعوت/بازیابی‌شدهٔ والد نیست. نشست محدود فعلی، برنامه‌ریز خصوصی را عمداً رد می‌کند؛ سرور آنلاین یکپارچه نیز برای تحویل این بسته هنوز آزموده نشده است.

| گزینه | تحویل | محدودیت |
|---|---|---|
| D-A — APK شخصی مستقل روی گوشی، پیشنهاد برای آزمون اولیه | بدون URL، پیامک یا سرور؛ دادهٔ واقعی فقط داخل همان گوشی، برنامهٔ هفتگی و اعلان محلی. رابط و ذخیره‌سازی واقعی، بدون دادهٔ ساختگی. جداسازی صریح از نسخهٔ آنلاین و بدون انتقال خودکار. | مشاهدهٔ والد، چنددستگاهی، همگام‌سازی و بازیابی از سرور ندارد. تکمیل هدف آنلاین خانواده محسوب نمی‌شود. انتخاب ساختار و بازیابی خصوصی کودک به نسخهٔ آنلاین موکول می‌شود. |
| D-B — فقط APK آنلاین | ساخت کلاینت روی API موجود؛ استفادهٔ کودک پس از تعیین سرور، تأیید ورود/حریم خصوصی و آزمون یکپارچه. دادهٔ محلی فقط کش/صف است. | بدون این پیش‌نیازها، APK نصب می‌شود ولی قابل بهره‌برداری کودک نیست؛ نشانی یا حساب نمایشی جای سرور واقعی قرار نمی‌گیرد. |

مبنای تصمیم: مالک پس از توضیح مانع API گفت «اگر بدون api فایل apk کار نمیکنه پس کارایی نداره کامل کن و فایل صحیح رو بده». سپس محدودهٔ نسخهٔ مستقل روی گوشی، بدون URL و بدون همگام‌سازی خانواده در پاسخ توضیح داده شد و مالک گفت «ادامه بده». این تأیید برای بستهٔ اولیهٔ D-A ثبت می‌شود؛ هدف آنلاین خانواده همچنان باقی است.

بستهٔ جدا با شناسهٔ آزمایشی `ir.lifeguide.app.device` و نام «لایف‌گاید شخصی» کنار APK قبلی نصب می‌شود. شناسهٔ نهایی نسخهٔ آنلاین `ir.lifeguide.app` حفظ می‌شود. دیتابیس SQLite خصوصی داخل همین بسته، مرجع واقعی نسخهٔ شخصی است؛ دادهٔ قبلی به‌صورت خودکار کپی/حذف/ارسال نمی‌شود. مجوز INTERNET از manifest نهایی نسخهٔ شخصی حذف و بررسی می‌شود. نشان محلی‌بودن و نبود بازیابی سروری در شروع/تنظیمات صریح است.

دادهٔ تست فقط ساختگی است. ساخت و تحویل debug اولیه مجوز انتشار تجاری، merge، deploy، DNS، ارسال دادهٔ واقعی به میزبان خارجی یا گسترش دسترسی نشست کودک نیست. برای اعلان، مجوز سیستم، وضعیت دقیق/تقریبی و محدودیت باتری/توقف اجباری باید صریح نمایش و آزموده شود.
