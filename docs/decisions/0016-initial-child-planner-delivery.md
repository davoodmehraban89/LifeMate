# 0016 — مسیر APK اولیهٔ برنامهٔ شخصی کودک

وضعیت: PROPOSED — تصمیم مالک لازم است؛ کد مجوز یا سرویس زنده تغییر نکرده است.

مالک بستهٔ برنامهٔ هفتگی، تکرار، یادآوری، تیک مستقل و حفظ داده پس از بازگشایی را برای APK اولیه تأیید کرد. تأیید، مجوز deploy یا بازکردن برنامهٔ خصوصی برای نشست دعوت/بازیابی‌شدهٔ والد نیست. نشست محدود فعلی، برنامه‌ریز خصوصی را عمداً رد می‌کند؛ سرور آنلاین یکپارچه نیز برای تحویل این بسته هنوز آزموده نشده است.

| گزینه | تحویل | محدودیت |
|---|---|---|
| D-A — APK شخصی مستقل روی گوشی، پیشنهاد برای آزمون اولیه | بدون URL، پیامک یا سرور؛ دادهٔ واقعی فقط داخل همان گوشی، برنامهٔ هفتگی و اعلان محلی. رابط و ذخیره‌سازی واقعی، بدون دادهٔ ساختگی. جداسازی صریح از نسخهٔ آنلاین و بدون انتقال خودکار. | مشاهدهٔ والد، چنددستگاهی، همگام‌سازی و بازیابی از سرور ندارد. تکمیل هدف آنلاین خانواده محسوب نمی‌شود. انتخاب ساختار و بازیابی خصوصی کودک به نسخهٔ آنلاین موکول می‌شود. |
| D-B — فقط APK آنلاین | ساخت کلاینت روی API موجود؛ استفادهٔ کودک پس از تعیین سرور، تأیید ورود/حریم خصوصی و آزمون یکپارچه. دادهٔ محلی فقط کش/صف است. | بدون این پیش‌نیازها، APK نصب می‌شود ولی قابل بهره‌برداری کودک نیست؛ نشانی یا حساب نمایشی جای سرور واقعی قرار نمی‌گیرد. |

تا پاسخ مالک، توسعهٔ مشترک برنامهٔ تکراری و پورت اعلان Android با دادهٔ ساختگی و آزمون محلی ادامه دارد. هیچ مسیر محلی جدید، انتشار عمومی، دادهٔ واقعی روی میزبان خارجی یا گسترش دسترسی نشست محدود فعال نمی‌شود. برای اعلان، مجوز سیستم، وضعیت دقیق/تقریبی و محدودیت باتری/توقف اجباری باید صریح نمایش و آزموده شود.
