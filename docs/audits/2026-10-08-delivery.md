# تحویل بسته ماندگاری محلی آرام

تاریخ: ۲۰۲۶-۱۰-۰۸. شاخه: `fix/local-task-persistence`؛ مبنا: `test/role-entry-apk@796d6bec16841020323bf67275f60c38048a0374`.

## نتیجه واقعی

API نمایشی حذف شد. تکلیف و فعالیت در سند نسخه‌دار روی دستگاه ذخیره، بازیابی و ویرایش می‌شوند؛ بایگانی رکورد را با `cancelled` نگه می‌دارد. نام، تم و شناسه پروفایل پایدارند؛ نوع پروفایل از نقش خانواده مستقل است. فرم‌ها اعتبارسنجی، وضعیت عملیات و خطا دارند و حالت محلی وارد صف Sync نسخه دارای Login نمی‌شود.

## محدودیت‌ها و اقدام بعدی

این بسته فقط نسخه آزمایشی بدون Login را اصلاح می‌کند. داده محلی Sync، backup سرور، احراز هویت یا رمزنگاری اختصاصی ندارد؛ uninstall می‌تواند داده را حذف کند. ظرفیت سند ۱ MiB است. چند پروفایل، تغییر دسته و بازگردانی آرشیو هنوز رابط ندارند. APK از تنظیم امضای debug فعلی پروژه استفاده می‌کند؛ پذیرش گوشی مالک و ارتقا از APK قبلی جداگانه تأیید نشده‌اند.

نقص‌های بازتولیدشده لاگ حساس، حساب غیرفعال، لغو سرپرست/اشتراک و parser/CORS Phase 6 در Backend هنوز اصلاح نشده‌اند. `profile_category` در API Production، سلامت opt-in، AI واقعی و Offline/Sync دارای Login هنوز ناقص‌اند. محصول کامل یا آماده انتشار اعلام نمی‌شود.

گام بعد: اصلاح parser/CORS/error/auth Backend با آزمون entrypoint واقعی، سپس قرارداد `profile_category` و مجوزهای خانواده. هیچ Merge، Release عمومی، تغییر DNS، قطع سرویس یا migration روی داده زنده در این بسته انجام نشده است.
