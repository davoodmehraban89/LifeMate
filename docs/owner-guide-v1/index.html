02 / واقعی امروز

امروز واقعاً چه داریم؟

لایف‌گاید شخصی Android؛ بستهٔ اولیه برای آزمون یک گوشی.

واقعی امروز · شواهد ثبت‌شده

بدون URL، API و ورود

نسخهٔ 0.7.2-personal.1 / code9، داده را در SQLite خصوصی همین گوشی نگه می‌دارد.

  • برنامهٔ یک‌باره، روزانه، روزدرمیان یا هفتگی؛ ساعت مستقل برای روزها.
  • تیک، ویرایش و بایگانی هر نوبت؛ نام دلخواه، نام همراه و چهار تم.
  • یادآوری فقط با انتخاب کاربر و مجوز Android؛ متن اعلان عمومی است.

روزهای هفته فارسی‌اند؛ تاریخ فعلی میلادی است. شناسهٔ بسته: ir.lifeguide.app.device

حد واقعی این تحویل

این APK آزمایشی debug است. خانواده، همگام‌سازی، خروجی، backup و بازیابی ندارد. حذف برنامه یا داده می‌تواند برنامه‌ها را از بین ببرد؛ برای اختلاف امضا، هیچ داده‌ای پاک نشود.

سند مبنا: PROJECT_STATE، بخش ۲۰ اکتبر؛ کد 3e36dfd. گوشی واقعی و ارتقای بدون حذف داده هنوز بررسی نشده‌اند.

گزارش آموزشی محدود

فقط سرپرست فعال و مجاز: عنوان تکلیف، درس، موعد، وضعیت و زمان ثبت‌شده با منبع روشن؛ زمان آخرین دریافت هم دیده شود.

شفافیت قبل از ثبت

کودک بداند چه کسی کدام داده را می‌بیند. لغو سرپرستی و نشست، روی سرور و نمایش آفلاین اعمال شود.

حریم خصوصی پیش‌فرض عوض نمی‌شود

گفت‌وگوی خصوصی، یادداشت آزاد، سلامت و اطلاعات روانی خودکار وارد گزارش والد نمی‌شوند. مدیر خانواده بودن، مجوز دیدن همهٔ داده‌ها نیست.

پذیرش لازم: یک فرزند و دو والد روی سه دستگاه، رد دسترسی فرد غیرمجاز، لغو مجوز، قطع/وصل اینترنت و نبود نمایش نادرست «زنده». نسخهٔ شخصی امروز این ارتباط را ندارد.

استخراج خودکار متن خصوصی، فرستادن خودکار به AI/عامل یا انتشار خودکار مجاز نیست. رضایت بازخورد از نقش مدیر خانواده جداست؛ این دفترچه هیچ جریان تازه‌ای را فعال نمی‌کند.

11 / پاسخ‌گویی و یادگیری

چرا تحویل طول کشید؟

توضیح صریح دربارهٔ ترتیب کار و فاصلهٔ کد تا استفاده.

01

دیر به مسیر کامل رسیدیم

مسیر «نصب کن و همان روز استفاده کن» دیر در اولویت قرار گرفت؛ بخش‌های زیاد، تجربهٔ کامل یک نفر را تضمین نکردند.

02

وابستگی اشتباه در تحویل

APK وابسته به سرور پیش از آماده‌شدن API تحویل شد و از مالک URL خواسته شد؛ آماده‌کردن نشانی درست، مسئولیت تیم فنی بود.

03

انباشت پیش از یکپارچه‌سازی

PRهای زنجیره‌ای و تغییرات زیرساخت طولانی شدند. CIهای موفق، قطعات را سنجیدند؛ محصول آنلاین خانواده هنوز به هم نرسید.

خرابی ابزار، علت اصلی نبود

خطای ابزار و کمبود دیسک زمان گرفتند، اما مسئلهٔ اصلی ترتیب تحویل و فاصلهٔ انتهابه‌انتها بود. تأخیر تقصیر کاربر نیست. عامل هم همیشه در پس‌زمینه فعال نیست و بین نوبت‌های اجرا ادامهٔ کار تضمین نمی‌شود.

هنوز باید حل شوند

گوشی فیزیکی و Safari، شبکهٔ ایران، میزبان و SMS، کلید پایدار انتشار، بازبین آموزشی و سیاست‌های حریم خصوصی/رضایت. هیچ‌کدام با زیباترشدن دفترچه یا سبزشدن یک CI تمام نمی‌شوند.
