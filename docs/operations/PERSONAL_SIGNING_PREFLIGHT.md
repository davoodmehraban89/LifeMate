# بررسی محلی امضا — فقط آماده‌سازی

این بسته مشکل نصب آپدیت را به‌تنهایی حل نمی‌کند. کلید خصوصی APK اولیه هنوز
**UNVERIFIED** است. نصب فعلی را حذف یا clear-data نکنید. بررسی موفقِ کلید،
مجوز انتشار یا اثبات حفظ داده نیست؛ تحویل APK همچنان **BLOCKED** است.

این ابزار روی رایانه اجرا می‌شود؛ به گوشی، شبکه، GitHub Secrets یا دادهٔ کودک
اتصال ندارد. هیچ کلیدی نمی‌سازد، جست‌وجو نمی‌کند، صادر/کپی نمی‌کند، امضا نمی‌کند
و گزارشی خودکار روی دیسک نمی‌نویسد. فقط آزمون‌ها کلیدهای موقت خیالی می‌سازند
و پس از پایان پاک می‌کنند. استفاده از کلید واقعی مالک در این بسته اجرا نشده است.

## بررسی بی‌خطر پیش‌نیازها

در checkout همین شاخه، Python3.11+ و **JDK کامل17 یا جدیدتر** در PATH لازم است.
این فرمان فقط baseline عمومی و Java را بررسی می‌کند. helper با ورودی خالی
کامپایل می‌شود؛ فایل کلید یا رمز درخواست/خوانده نمی‌شود:

```powershell
python scripts/signing_preflight.py check
```

خروجی `status: CHECKED` و exit0 یعنی پیش‌نیاز عمومی در همان رایانه بررسی شد؛
`keyInspection: UNVERIFIED` باقی می‌ماند. `jdk17_required` و exit2 یعنی Java
کامل/سازگار پیدا نشد، یا helper کامپایل/اجرا نشد. این کنترل، نصب خودکار ابزار ندارد.

## اقدام آیندهٔ مالک، تنها پس از مجوز جداگانه

**فعلاً این مرحله را روی کلید واقعی اجرا نکنید.** اجازهٔ فعلی فقط آماده‌سازی و
آزمون ساختگی است. اگر بعداً بررسی محلی کلید تأیید شد، مالک یک فایل مشخص و
alias معلوم خودش را انتخاب می‌کند؛ جست‌وجوی خودکار نداریم:

```powershell
python scripts/signing_preflight.py inspect --keystore "C:\LOCAL-ONLY\chosen-key.jks" --alias "YOUR_LOCAL_ALIAS" --acknowledge-owner-local-inspection
```

مسیر و alias بالا فقط جای‌نگهدارند. رمز فایل و رمز entry در ترمینال پنهان
پرسیده می‌شوند؛ Enter در رمز دوم یعنی همان رمز اول. رمز را در فرمان، متغیر
محیطی، چت، تیکت یا GitHub ننویسید. فایل کلید را ارسال نکنید. خروجی هیچ نام
دارندهٔ certificate، alias، مسیر، رمز، کلید خصوصی یا امضای challenge ندارد.
فقط اثرانگشت عمومی و نتیجهٔ محدود را، در صورت نیاز، گزارش کنید.

پایپ‌کردن رمز، اجرای بدون TTY، ورودی symlink/FIFO/directory، فایل بزرگ‌تر از
2MiB، رمز/alias نامعتبر یا خطای Java رد می‌شود. JKS و PKCS12 با entry خصوصی
RSA/EC پشتیبانی می‌شوند؛ فقط داشتن certificate عمومی کافی نیست. اثبات محلی
با امضا و بررسی یک challenge تصادفی در حافظه انجام می‌شود؛ APK امضا نمی‌شود.

## معنی خروجی

| فیلد | معنی محدود |
| --- | --- |
| `status: INSPECTED`، exit0 | فایل انتخاب‌شده در همان اجرا خوانده و keypair محلی بررسی شد؛ اجازهٔ تحویل نیست |
| `signerCompatibility: MATCH` | اثرانگشت با گواه عمومی APK تحویلی برابر است؛ نصب واقعی گوشی هنوز بررسی نشده |
| `signerCompatibility: DIFFERENT` | این کلید مسیر آپدیت مستقیم APK تحویلی را اثبات نمی‌کند؛ نصب را حذف نکنید |
| `debugCertificate: true` | CN گواه از نوع Android Debug است؛ برای release پذیرفته نیست؛ حتی در صورت MATCH |
| `privateKeyProof: true` | entry خصوصی با رمز باز شد و challenge با public key همان گواه تأیید شد |
| `certificateCurrentlyValid` | صرفاً اعتبار زمانی certificate؛ معیار کامل انتشار یا سازگاری Android نیست |
| `status: REFUSED`، exit2 | بررسی کامل نشده؛ فقط کد خطای ثابت، بدون جزئیات حساس |
| `delivery: BLOCKED` | در همهٔ نتایج ثابت؛ کلید پایدار، package/version و آزمون ارتقای حفظ داده هنوز جداگانه لازم‌اند |

گواه تحویلی در [baseline عمومی](personal-delivered-baseline.json) ثبت شده است.
این ابزار baseline را تغییر نمی‌دهد و گزینهٔ جایگزینی آن ندارد. تطبیق کلید
قدیمی debug به معنی تأیید آن برای انتشار پایدار نیست؛ سیاست امضا تغییر نکرده.

## حدود آزمون

دستورهای قابل تکرار با دادهٔ ساختگی:

```powershell
python -m unittest discover -s scripts/tests -p "test_signing*.py" -v
python -m unittest discover -s apps/lifemate/tool -p "*_test.py" -v
```

آزمون‌ها کلید موقت RSA/EC، ورود دوباره، نسخهٔ کپی **ساختگی**، رمز اشتباه،
certificate-only، گواه debug، فایل خراب، خطای helper و حفظ hash ورودی را
می‌سنجند. نتیجهٔ واقعی اجرا در گزارش evidence همین بسته درج می‌شود؛ وجود
فرمان در این راهنما به معنی اجرای موفق آن نیست.

تعامل واقعی Windows/رمز مخفی/ACL، بازیابی نسخهٔ پشتیبان کلید مالک، custody،
گوشی، نصب/آپدیت/اعلان و انتقال دادهٔ واقعی **UNVERIFIED** هستند. پاک‌شدن کامل
رمز از حافظهٔ Python/JVM، crash dump سیستم، JDK آلوده، مهاجم دارای دسترسی
مدیر و filesystem مهاجم تضمین نمی‌شود. ابزار فقط آخرین جزء مسیر symlink
را رد می‌کند؛ جداسازی کامل پوشه‌های والد یا احراز اصالت فایل را ادعا نمی‌کند.

برای بستهٔ قابل نصب بعدی هنوز باید کلید مناسب واقعاً در اختیار مالک باشد یا
مسیر بازیابی محلی جداگانه تأیید شود، سپس APK دقیق قدیمی→جدید با دادهٔ ساختگی
و در نهایت گوشی با مجوز مرتبط آزموده شود. این بسته هیچ‌یک را انجام نمی‌دهد.
