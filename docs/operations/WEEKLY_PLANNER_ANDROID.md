# برنامهٔ هفتگی و APK آزمایشی — ۲۰۲۶-۱۰-۱۸

این بسته تکمیل محصول آنلاین یا مجوز استفادهٔ کودک از نشست محدود فعلی نیست. دادهٔ آزمون فقط ساختگی است. سرور عمومی یکپارچه و ورود خصوصی مستقل کودک آمادهٔ پذیرش نیستند؛ انتخاب نسخهٔ مستقلِ صرفاً روی گوشی در [ADR0016](../decisions/0016-initial-child-planner-delivery.md) هنوز PROPOSED است. هیچ URL حدسی، حساب مشترک یا پاسخ نمایشی جایگزین آن نشده است.

## رفتار پیاده‌شده

- «برنامه من»: انتخاب هفته و روز از شنبه، کار یک‌باره با شروع/پایان، برنامهٔ روزانه یا روزدرمیان، روزهای منتخب هفته با ساعت متفاوت هر روز، تاریخ پایان اختیاری و یادآوری.
- نوبت‌ها رکورد واقعی `plan_item` در PostgreSQL هستند؛ کلید یکتای مجموعه/تاریخ اصلی از تکرار جلوگیری می‌کند. تیک، برداشتن تیک، جابه‌جایی و بایگانی هر نوبت مستقل است. در این نسخه تغییر الگوی کل مجموعه در UI وجود ندارد؛ برای هر نوبت می‌توان زمان را تغییر داد.
- برنامهٔ تکراری خصوصی است؛ نوع پروفایل مجوز اشتراک نمی‌دهد. نشست `child_education` همچنان403 می‌گیرد. خانهٔ کودک فقط برنامهٔ همان مالک را با قدم بعدی، کارهای امروز و پیشرفت روز نمایش می‌دهد.
- ثبت روی سرور با نگه‌داری در کش/صف همان حساب و همان نشانی API فرق دارد. قطع پاسخ، شناسه و بدنهٔ درخواست را تغییر نمی‌دهد. پیش‌نویس تکراریِ آفلاین تا تأیید سرور نوبت یا اعلان ساختگی تولید نمی‌کند. خطای قطعی در «تغییرهای معلق و تعارض‌ها» با انتخاب صریح و نگه‌داشتن پیش‌نویس قابل بررسی است.
- ایجاد اولیه تا۶۰روز نوبت می‌سازد؛ بازکردن هفته، روزهای مفقود همان هفته را بدون بازنویسی استثناها تولید می‌کند. برنامه برای همهٔ آینده از پیش روی گوشی تولید نمی‌شود.

## اعلان Android

از منو «اعلان روی این گوشی» را باز کنید. مجوز اعلان سیستم و فعال‌سازی کاربر لازم است. نام همراه، یک ترجیح محلی به‌ازای حساب/سرور است؛ نام بسته و نام سیستم Android همچنان لایف‌گاید می‌ماند.

فقط یادآوری مالک از دریافت تازهٔ API زمان‌بندی می‌شود؛ متن خصوصی تکلیف در اعلانِ صفحهٔ قفل قرار نمی‌گیرد. مهلت دریافت تازه حداکثر۲۴ساعت است. برای تمدید، برنامه را با اتصال معتبر باز کنید؛ کش آفلاین این مهلت را تمدید نمی‌کند. خارج‌کردن از صف/تغییر آفلاین/تکمیل، اعلان قدیمی همان مورد را حذف می‌کند. خاموش‌کردن و خروج، زمان‌بندی را لغو می‌کند؛ درخواست معلق نباید دوباره آن را فعال کند.

مجوز «هشدارها و یادآوری‌های دقیق» اختیاری است. در نبود مجوز، وضعیت «تقریبی» نمایش داده می‌شود. تنظیم صدا و محدودیت باتری به Android و کانال اعلان وابسته است. بستن عادی، توقف اجباری، راه‌اندازی مجدد، حالت کم‌مصرف و محدودیت سازنده یکسان نیستند؛ **تحویل اعلان واقعی روی گوشی، صدا و زمان دقیق UNVERIFIED است**. آلارم تمام‌صفحه یا ویجت در این بسته نیست. PWA از این پورت Android استفاده نمی‌کند.

## پیش‌نیاز و نصب

Backend باید همین API و migration0026 را داشته باشد؛ اعمال روی سرویس زنده هنوز مجاز نیست. مسیر محلی موجود، Stage0 و متغیرهای محیطی همان پروژه است. APK آنلاین بدون API معتبر کاربر را به تنظیم اتصال می‌برد؛ ذخیرهٔ URL به‌معنی اتصال موفق نیست. برای آزمون محلی از دادهٔ ساختگی، HTTPS مورد اعتماد دستگاه و حساب مستقل معتبر استفاده کنید. کد دعوتِ محدود را به حساب خصوصی تبدیل نکنید.

APK این مرحله با گواهی debug ساخته می‌شود، انتشار رسمی و امضای release مالک نیست. اگر Android خطای ناسازگاری امضا نشان داد، برنامهٔ قبلی را برای رفع خطا حذف نکنید؛ دادهٔ ارسال‌نشده ممکن است از دست برود. نسخهٔ امضاشدهٔ پایدار و آزمون ارتقا جداگانه لازم است. مخزن، کلید امضا یا اطلاعات حساب در UI عمومی نمایش داده نمی‌شود.

## سناریوی پذیرش روی گوشی — هنوز اجرا نشده

1. با حساب ساختگی، شنبه تا چهارشنبه مدرسه تعریف کنید؛ دو روز ساعت پایان متفاوت داشته باشند. یک کار یک‌باره و یک برنامهٔ روزدرمیان هم ثبت کنید.
2. با فراخوانی مستقل API/SQL، تعداد، مالک و ساعت نوبت‌ها را بررسی کنید. یک نوبت را تیک بزنید؛ روزهای دیگر نباید تیک بخورند.
3. برنامه را عادی ببندید و دوباره باز کنید؛ همان نوبت و ساعت‌ها باید بمانند. زمان یک نوبت را تغییر دهید و دوباره باز کنید.
4. اینترنت را قطع کنید، تیک را تغییر دهید، برنامه را ببندید و باز کنید. تغییر باید معلق بماند؛ پس از اتصال فقط یک mutation پذیرفته شود.
5. برای چند دقیقهٔ آینده یادآوری تعریف و اعلان گوشی را فعال کنید. وضعیت دقیق/تقریبی و پایان مهلت را ثبت کنید؛ با صفحهٔ خاموش امتحان کنید.
6. هنگام دریافت کند، اعلان را خاموش کنید؛ پس از پایان دریافت نباید خودکار فعال شود. تکمیل/تغییر زمان نباید اعلان قدیمی بگذارد. خروج نباید اعلان حساب قبلی بدهد.
7. پیش از موعد تیک را بردارید؛ یادآوری آینده باید دقیقاً یک بار برگردد. یک کار را تمام کنید؛ پیشرفت خانه باید آن را حساب کند.

نتیجهٔ گوشی واقعی، نصب/ارتقا، ایران بدون VPN، Safari، میزبان عمومی و تحویل SMS همگی **UNVERIFIED** هستند. ادعای آماده‌بودن بهره‌برداری خانوادگی تا رفع مانع ورود/سرور و اجرای پذیرش مجاز نیست.
