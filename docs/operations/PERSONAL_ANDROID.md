## رفتار قابل بررسی

- نام دلخواه و گروه پروفایل محلی؛ گروه، مجوز یا نقش خانوادگی نیست.
- برنامهٔ یک‌باره، هر روز، یک روز در میان، یا روزهای انتخابی هفته با ساعت‌های متفاوت.
- ساعت شروع/پایان و یادآوری اختیاری؛ تیک، ویرایش یک نوبت، بایگانی نوبت یا کل برنامه.
- SQLite خصوصی و تراکنشی روی همان گوشی، UUID پایدار و نسخهٔ schema؛ خطای خواندن/نوشتن نمایش داده می‌شود و داده خودکار بازنشانی نمی‌شود.
- سه مقصد «امروز / هفته / تنظیمات»، نام همراه و چهار تم قابل تغییر. تاریخ‌های این بسته میلادی‌اند و روزهای هفته فارسی هستند.
- اعلان با انتخاب صریح کاربر و مجوز Android؛ نام همراه + متن عمومی، بدون عنوان خصوصی کار. حداکثر ۱۲۸ یادآوری نزدیک‌تر در ۲۸ روز؛ برای آماده‌شدن روزهای بعد برنامه را مرتب باز کنید.

## نصب و پذیرش روی گوشی

نام نصب «لایف‌گاید شخصی»، شناسهٔ جدا `ir.lifeguide.app.device`، نسخه `0.7.2-personal.1` / code9 است؛ برنامهٔ آنلاین `ir.lifeguide.app` و اطلاعات قبلی آن جدا می‌مانند. APK آزمایشی debug است؛ به‌عنوان release امضاشده معرفی نشود.

۱. `LifeGuide.apk` همین تحویل را نصب کنید؛ برنامهٔ قبلی را پاک نکنید.
۲. نام دلخواه و گروه را وارد کنید؛ آدرس سرور نباید پرسیده شود.
۳. یک برنامهٔ هفتگی با دو روز و دو ساعت متفاوت بسازید، و یک عادت یک‌روزدرمیان.
۴. تیک یک نوبت و ساعت نوبت دیگری را عوض کنید؛ برنامه را عادی ببندید و باز کنید. تغییرها باید بمانند.
۵. در تنظیمات، اعلان را روشن و مجوز سیستم را تأیید کنید. برای آزمون، یک نوبت چند دقیقهٔ بعد و یادآوری «هنگام شروع» بسازید؛ برنامه را عادی ببندید و اعلان را بررسی کنید.
۶. همان نوبت را پیش از موعد تیک بزنید/بایگانی کنید؛ اعلان نباید برای آن نمایش داده شود. خاموش‌کردن اعلان باید یادآوری‌های فعال را لغو کند.

صدا/لرزش، Doze، reboot، مجوزهای سازنده، نصب/ارتقا و زمان‌بندی approximate روی گوشی واقعی **UNVERIFIED** هستند. زمان‌بندی دقیق به مجوز سیستم وابسته است؛ اعلان تضمین شنیدن آلارم نیست. Force-stop با بستن عادی فرق دارد و می‌تواند اعلان را متوقف کند.

**داده فقط روی این گوشی است.** حذف برنامه، پاک‌کردن داده یا خرابی/گم‌شدن گوشی می‌تواند برنامه‌ها را از بین ببرد. بازیابی سرور، خروجی/backup و همگام‌سازی این بسته وجود ندارد. برای حل اختلاف امضا هرگز حذف داده/برنامه پیشنهاد نشود. حفظ کلید و مسیر ارتقای بدون حذف داده هنوز **UNVERIFIED** است؛ گواهی امضای این تحویل باید ثبت شود.

## ساخت و کنترل محلی/CI

```sh
cd apps/lifemate
flutter pub get
flutter analyze
flutter test
python3 -m unittest discover -s tool -p '*standalone*test.py' -v
ORG_GRADLE_PROJECT_lifeguideDevicePlanner=true flutter build apk --debug \
  --target=lib/standalone_main.dart --dart-define=LIFEGUIDE_STANDALONE=true \
  --build-name=0.7.2-personal.1 --build-number=9
python3 tool/check_standalone_apk.py build/app/outputs/flutter-apk/app-debug.apk
```

Workflow `standalone-personal-apk.yml` ابتدا APK واقعی کاربر را می‌سازد و اولین اجرای آن را ثبت می‌کند؛ سپس فقط در AVD تازه، fixture هم‌امضا را روی همان نصب آزمایشی جایگزین می‌کند. fixture پایگاه جدا `standalone_acceptance.sqlite` دارد و هرگز توزیع نمی‌شود. آزمون آن SQLite واقعی + SQL مستقل بعد از close/reopen + مرگ عادی پردازش + NotificationManager واقعی + لغو پیش از موعد است. ساخت/اجرای واقعی و دستور/خروجی در receipt تحویل ثبت می‌شوند؛ تعریف workflow به‌تنهایی نتیجهٔ موفق نیست.

هیچ merge، deploy، تغییر DNS یا دادهٔ واقعی مجاز نشده و در این بسته انجام نمی‌شود. PWA/Safari، خانوادهٔ آنلاین، ورود کودک/والد و محتوای درسی جزو پذیرش این APK شخصی نیستند.
