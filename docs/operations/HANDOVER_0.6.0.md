# LifeGuide 0.6.0 — تحویل بسته آموزش آزمایشی

شاخه `feat/aparat-learning-library` و [PR پیش‌نویس ۱۱](https://github.com/davoodmehraban89/LifeMate/pull/11) روی بسته آنلاین قبلی قرار دارند؛ main ادغام نشده است. [شواهد اجرا و محدودیت‌ها](../audits/2026-10-11-learning-verification.md) مرجع نتیجه آزمون هستند. این نسخه مدرسه کامل یا سرویس عمومی آماده استفاده نیست.

## اکنون چه اقدامی لازم است؟

وقتی به رایانه دسترسی ندارید، اقدامی لازم نیست. کادر URL در APK **نشانی HTTPS API مشترک خانواده** را می‌خواهد؛ نصب APK یا ذخیره URL، سرور را راه‌اندازی نمی‌کند. [بررسی دامنه و اتصال](../audits/2026-10-11-apk-connection.md) نشان داد مسیرهای بررسی‌شده دامنه عمومی هنوز پاسخ سازگار این نسخه را نمی‌دهند. دامنه یا `/api` را حدس نزنید و DNS را تغییر ندهید.

## پس از دسترسی به رایانه: فقط Stage 0 با داده ساختگی

1. یک checkout مستقل از شاخه آموزش آماده کنید. تغییرات پوشه قبلی را با reset یا force حذف نکنید. خروجی `LifeGuide-web` همان اجرای CI را از [صفحه ساخت اصلاح‌شده](https://github.com/davoodmehraban89/LifeMate/actions/runs/38148788571) همراه `build-provenance.json` در `apps/lifemate/build/web` استخراج کنید. موفقیت/شناسه دقیق artifact را در رسید نهایی بررسی کنید؛ وجود workflow به معنی موفقیت همه jobها نیست.
2. Docker Desktop/WSL2، Node 22 و mkcert لازم‌اند. به [Stage 0](STAGE0.md) برای اعتماد عمومی CA روی Android/iPhone و فایروال محدود LAN مراجعه کنید. فرمان‌های زیر روی Windows مالک **UNVERIFIED** هستند؛ جای IP نمونه، IP واقعی رایانه را بگذارید:

```powershell
New-Item -ItemType Directory -Force deployment/tls | Out-Null
mkcert -install
mkcert -cert-file deployment/tls/server.pem -key-file deployment/tls/server-key.pem 192.168.1.10 localhost 127.0.0.1
mkcert -CAROOT
node scripts/prebuilt-web-check.mjs apps/lifemate
./scripts/local-deploy.ps1 -Origin https://192.168.1.10 -PrebuiltWeb
docker compose ps
```

3. فقط گواهی **عمومی** CA را برای اعتماد به دستگاه‌های آزمون منتقل کنید؛ کلید CA/سرور در رایانه و خارج Git بماند. هشدار TLS را دور نزنید. وقتی Compose سالم و گواهی مورد اعتماد است، PWA روی `https://LAN-IP/` و API روی `https://LAN-IP/api` هستند. برای Android/LAN، APK عمومی CI حاوی CA رایانه شما نیست؛ build debug جدا با `LIFEGUIDE_DEBUG_CA_BASE64` و گواهی عمومی خودتان طبق [Stage 0](STAGE0.md#آماده‌سازی-windows) لازم است و پذیرش دستگاه هنوز UNVERIFIED است. سپس نشانی کامل API همان شبکه را یک‌بار در APK وارد کنید. نصب گواهی در گوشی به‌تنهایی اعتماد HTTP برنامه را اثبات نمی‌کند؛ define آزمایشی در release ممنوع است.
4. fixture خانواده با حساب مستقل کودک/مادر/پدر را مطابق بخش «حساب و round-trip ساختگی» در [Stage 0](STAGE0.md) بسازید. رمز فقط در محیط خصوصی خودتان بماند. ورود این fixture تأیید تحویل ایمیل/SMS نیست؛ provider واقعی هنوز فعال/آزموده نشده است.
5. سناریوی تکلیف ریاضی، گزارش مجاز هر دو والد، تایمر با توقف/ادامه و بستن/بازکردن سه دستگاه را اجرا کنید. سپس «مدرسه من»، انتخاب پایه، بازکردن یک بخش از میانه کتاب، ثبت پیشرفت شخصی، بستن/بازکردن و تغییر آفلاین/اتصال دوباره را بررسی کنید. پیشرفت باید تأیید سرور و وضعیت تغییر ارسال‌نشده را روشن نشان دهد؛ گزارش شخصی یا تایمر اثبات یادگیری نیست.
6. بازخورد اختیاری را با متن ساختگی و رضایت صریح ارسال و رضایت را پس بگیرید؛ متن سرور باید حذف شود. موضوع خصوصی خانواده/سلامت/گفت‌وگو را برای گزارش خطای محتوا وارد نکنید.

برای توقف و راه‌اندازی دوباره، `docker compose stop` و `docker compose start` داده volume را حفظ می‌کنند. برای استفاده معمول `down -v` اجرا نکنید. checker خروجی وب نامنطبق را رد می‌کند؛ با stamp دوباره، خروجی قدیمی را معتبر معرفی نکنید.

## APK و امضای انتشار

خروجی [APK اصلاح‌شده](https://github.com/davoodmehraban89/LifeMate/actions/runs/38148788571/artifacts/11706166986) با نام `LifeGuide-debug.apk` داخل ZIP، **آزمایشی** است. شناسه نهایی `ir.lifeguide.app`، نسخه 0.6.0 و code 5 هستند؛ manifest/hash/signature واقعی هر فایل باید با [رسید همان run](../audits/evidence/ci-learning-final-2026-10-11.json) مقایسه شود. هر سه job این run واقعاً موفق شدند؛ این به معنی نصب/پذیرش دستگاه نیست. اختلاف گواهی Debug می‌تواند ارتقای مستقیم را رد کند؛ برنامه یا داده دارای کار ارسال‌نشده را برای رفع خطای امضا حذف نکنید. نصب و ارتقای واقعی دستگاه هنوز UNVERIFIED است.

`LifeGuide.apk` با امضای انتشار مالک هنوز ساخته نشده است. روش ساخت کلید پایدار خارج مخزن و secretهای محیط حفاظت‌شده در [تحویل قبلی، بخش کلید رسمی](HANDOVER_0.5.1.md#2-خروجی-apk-و-کلید-رسمی) آمده است؛ کلید/رمز در چت یا Git قرار نگیرد. ساخت artifact آزمایشی مجوز انتشار عمومی نیست.

## چه چیزی هنوز آموزش آماده استفاده نیست؟

۲۱۷ کتاب، ۱۳۷۳ بخش و ۱۳۴۸ ویدیو فقط فهرست پژوهش‌اند. **ویدیوی واقعی منتشرشده با بازبینی کامل: صفر؛ بانک سؤال واقعی منتشرشده: صفر.** کتاب‌های متوسطه هنوز تأیید چاپ ندارند. برنامه ویدیو/سؤال بررسی‌نشده را به کودک عرضه نمی‌کند؛ دیدن پیام «در انتظار بازبینی» در این نسخه رفتار مورد انتظار است، نه اثبات پوشش کامل آموزش. [مراحل بررسی هر درس](LEARNING_CONTENT.md) شامل تطبیق چاپ/هدف، مشاهده کامل، صحت، تناسب، حقوق نمایش و سؤال با پاسخ توضیحی است.

انتخاب میزبان، مجوز انتقال DNS، provider پیامک/ایمیل، کلید امضای مالک و پذیرش واقعی Android/Safari/ایران همچنان مراحل جدا هستند. [میزبانی](../decisions/0009-provider-neutral-hosting.md)، [انتقال به سرور داخلی و rollback](DOMESTIC_MIGRATION.md). هیچ ثبت‌نام، خرید، تغییر زنده، انتقال داده واقعی، merge یا انتشار عمومی در این بسته انجام نشده است. AI/voice، مشاوره بالینی و داده حساس سلامت غیرفعال‌اند؛ گردش ادمین بازخورد و توسعه خودکار هنوز اجرا نشده است.
