## چگونه بررسی کنید

۱. خانه ← برنامهٔ من ← یک تکلیف ← برگشت. در همان محیط یک کار ساختگی اضافه/ویرایش کنید.
۲. درس‌ها ← ریاضی ← جایگاه ویدئو/تمام‌صفحه ← آزمونک ده پرسشی ← توضیح پاسخ.
۳. تمرکز ← شروع، توقف، ادامه یا استراحت کوتاه.
۴. بالای پیش‌نمایش، نمای والد ← کارت فرزند ← گزارش نمونه. تغییر نما ابزار بازبینی طرح است؛ ورود واقعی یا تغییر مجوز نیست.
۵. دکمهٔ «شمای ۱۲ صفحه» تصویر کنارهم صفحه‌ها را نشان می‌دهد؛ PNG/PDF برای زوم مناسب‌اند. قاب‌های برد برای نمایش کامل محتوا عمداً بلندتر از قاب پیش‌نمایش موبایل‌اند.

پیشنهاد: در گوشی، نوار اصلی پایین ثابت؛ در هر بخش صفحه و بازگشت مشخص. روی خانه همه منوها در اندازه۳۲۰ و۳۹۰بدون اسکرول دیده می‌شوند؛ فهرست‌های بلند در همان صفحه اسکرول داخلی دارند. این یک صفحهٔ معرفی با لینک‌های جهشی نیست.

همه اسم‌ها، زمان‌ها و نتیجه‌ها ساختگی‌اند. تغییرات فقط در حافظهٔ پیش‌نمایش هستند و پس از بازکردن مجدد حفظ نمی‌شوند؛ برنامهٔ واقعی باید از API/DB موجود استفاده کند. محتوا و پرسش‌ها تأیید معلم نشده‌اند. ویدیوی واقعی متصل نیست. نمونه اعلان، آلارم دستگاه/ویجت نیست. هیچ SMS/AI یا دادهٔ حساس استفاده نمی‌شود.

## خروجی و بازیابی کار

منبع طرح درsrc و فونت/مجوز درassets موجود است. `DESIGN_STATE.json` شناسه نسخهٔ بوم، وضعیت و گام بعد را ثبت می‌کند. exports شامل خروجی‌های مستقل است؛ ادامهٔ کار وابسته به تاریخچه چت نیست. HTML کامل حاوی CSS،React و فونت است؛ با سرو یک فایل ازHTTPمحلی درChromium آزموده شد. بازکردن مستقیمfile://در محیط اجرای ما با policy مسدود بود؛ Safariگوشی و این روش بازکردن هنوزUNVERIFIED هستند.

مبنای بصری: مسیر آموزشی Khan Academy، برنامهٔ روز Todoist و فضای مشترک FamilyWall. مرجعِ واحدِ «بی‌نقص» ادعا نمی‌شود و دارایی‌های آنها کپی نشده‌اند. AI/سلامت و سیاست داده تغییر نمی‌کند.

طرحReact/HTML فقط ابزار بررسی است؛ تصمیمی برای تبدیل Flutter بهReact یا تغییر معماری گرفته نشده است. پس از تأیید، این صفحه‌بندی روی کلاینت موجود پیاده می‌شود؛ auth/permission/data پذیرش جداگانه لازم دارند. هیچ merge/deploy یا تغییرDNS انجام نشده است.

## بازاجرای بررسی طرح (اختیاری، مستقل از محصول)

ابزارهای استفاده‌شده: Node،React/ReactDOM 19.3.1،esbuild 0.25.12،Playwright 1.62.1 وChromium 151.0.7922.173. نصب ابزارها در پوشهٔ موقت است، نه کلاینت Flutter. برای بازتولید، از ریشهٔ مخزن:

```sh
npm install --prefix /tmp/lifeguide-design-tools --no-save react@19.3.1 react-dom@19.3.1 esbuild@0.25.12 playwright@1.62.1
NODE_PATH=/tmp/lifeguide-design-tools/node_modules node design-review/mobile-v1/tools/build.mjs
python -m http.server 8769 --bind 127.0.0.1 --directory design-review/mobile-v1/exports
# در ترمینال دوم؛ CHROMIUM_PATH را متناسب با دستگاه تنظیم کنید:
NODE_PATH=/tmp/lifeguide-design-tools/node_modules CHROMIUM_PATH=/usr/bin/chromium DESIGN_BASE_URL=http://127.0.0.1:8769/LifeGuide-preview.html node design-review/mobile-v1/tools/check.cjs
```

خروجی اجرای واقعی این نشست: `passed: 11`،`javascriptErrors: []`،`externalRequests: []`. تست ازChromium وHTTPمحلی استفاده کرد. جایگزین پذیرشSafari/Androidواقعی نیست.
