# LifeGuide-Design-v2

**بستهٔ طراحی برای بررسی مالک؛ منتظر تأیید. محصول عملیاتی نیست.** همهٔ اطلاعات ساختگی‌اند. هر صفحه برچسب «طرح تعاملی با داده ساختگی» دارد. هیچ شماره، ایمیل، کد ورود یا مشخصات واقعی دریافت نمی‌شود؛ هیچ اتصال، ارسال، ذخیرهٔ پایدار، دانلود دادهٔ شخصی یا حذف حساب وجود ندارد.

## مسیرهای پیشنهادی بررسی

۱. خانه ← شروع یکی از چهار کار ← جزئیات ← انجام شد؛ سپس خانه و پیشرفت نمونه را ببینید. منوهای تکراری خانه حذف شده‌اند. یادآوری و گزارش شخصی از بالای خانه باز می‌شوند.

۲. ابزار بررسی ← خوش‌آمد ← انتخاب والد ← ورود نمایشی ← کد اشتباه، منقضی، مهلت ارسال مجدد و محدودیت تلاش. شماره و کد، فقط مقادیر پوشانده‌شده/آماده و غیرقابل ویرایش‌اند؛ هیچ پیامکی ارسال نمی‌شود.

۳. والد ← خانواده ← پروفایل ساختگی کودک ← متن رضایت نمایشی ۰۲ ← کارت دعوت نمونه. مسیر دانش‌آموز: کد دعوت و PIN نمایشی ← «والدم چه چیزی می‌بیند» ← خانه. اینها پیشنهاد شکل جریان‌اند، نه تصویب هویت/رضایت یا سیاست تازه.

۴. درس‌ها ← عددهای صحیح ← توضیح و مثال ← تمرین ← آزمونک ده‌سؤالی ← نمرهٔ همان پیش‌نمایش ← مرور پاسخ‌ها ← دوباره امتحان کن. با بازکردن مجدد، پاسخ‌ها برمی‌گردند؛ نمره ذخیره یا برای والد ارسال نمی‌شود. محتوای اصیلِ ساختگی، تأیید معلم نشده است. وضعیت reviewed فقط fixture برای طراحیِ فیلتر کودک است؛ هیچ منبع آموزشی تأییدشده یا ویدئویی وجود ندارد.

۵. تنظیمات ← مدیریت حساب نمونه ← خروج از خانواده، خروجی داده یا حذف حساب ← مرحلهٔ دوم ← پایان شبیه‌سازی. نتیجه هیچ‌گاه «حساب حذف شد» یا «داده ارسال شد» نیست.

۶. در هر صفحهٔ اصلی، از ابزار بررسی حالت خالی، بارگذاری، خطا، آفلاین/صف، تعارض، پایان نشست و ۴۲۹ را انتخاب کنید. «تلاش دوباره» و انتخاب نسخه فقط همین نمایش موقت را تغییر می‌دهند.

## آنچه تغییر نکرده است

مرز نمایش v1 حفظ شده: والد تکلیف مشترک، خلاصهٔ زمان ثبت‌شدهٔ مجاز و پیشرفت آموزشی قابل اشتراک را می‌بیند؛ یادداشت خصوصی، گفت‌وگو، سلامت و نمرهٔ خصوصی آزمونک وارد گزارش والد نمی‌شوند. ناوبری والد حداکثر پنج مقصد مستقل دارد و درس/تمرکز کودک را به حساب او باز نمی‌کند. [جزئیات](docs/PRIVACY_DISPLAY.md).

Flutter، Backend، دیتابیس، سایت زنده، DNS و معماری اپ تغییر نکرده‌اند. AI، سلامت، پرداخت و چند درس خارج از این بسته‌اند. نمادها SVG سادهٔ همین طرح‌اند؛ لوگو یا دارایی محصول دیگری کپی نشده است. فونت محلی با [مجوز](assets/FONT-LICENSE.txt) همراه است.

## بازاجرای مستقل

Node و Python و Playwright/Chromium محلی لازم‌اند؛ ابزار طراحی به Flutter یا Backend وابسته نیست. وابستگی Playwright در محیط این بررسی از نصب موجود خوانده شد؛ `NODE_PATH` و `CHROMIUM_PATH` را متناسب با رایانهٔ خود تنظیم کنید.

```sh
node tools/build.mjs
python -m http.server 8772 --bind 127.0.0.1 --directory exports
# در ترمینال جدا، از ریشهٔ همین بسته:
NODE_PATH=/path/to/node_modules CHROMIUM_PATH=/path/to/chromium \
  DESIGN_BASE_URL=http://127.0.0.1:8772/LifeGuide-preview.html node tools/check.cjs
NODE_PATH=/path/to/node_modules CHROMIUM_PATH=/path/to/chromium \
  DESIGN_BASE_URL=http://127.0.0.1:8772/LifeGuide-preview.html node tools/export.cjs
```

خروجی checker در `exports/verification.json` ثبت می‌شود؛ شکست هر حد فونت، کنتراست، لمس، سرریز/بریدگی، بزرگ‌نمایی یا bidi، فرمان را ناموفق می‌کند. این سنجشِ Chromium جای ارزیابی کامل WCAG، screen reader یا پذیرش کاربر واقعی نیست.

**UNVERIFIED:** Safari، Android/iPhone واقعی، دسترسی از ایران، نصب PWA، پخش واقعی ویدئو، آزمون دانش‌آموز و هر عملکرد محصول/سرور. هیچ merge یا deploy انجام نشده است. پس از تحویل برای تأیید مالک توقف می‌شود.
